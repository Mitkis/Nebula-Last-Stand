🎮 HOW TO PLAY

Action	Keyboard
Move Up	W / ↑
Move Down	S / ↓
Move Left	A / ←
Move Right	D / →
Shoot	SPACE
Hyper Beam	E / X
Pause	ESC / P
Mute	M

Additional controls:

* Mouse movement and left-click shooting.
* Optional mouse flight mode.
* Mobile virtual joystick and touch buttons.
* Optional automatic firing.

⸻

🔊 SOUND & ATMOSPHERE

Nebula features a custom procedural audio engine built using the Web Audio API.

No external audio files are required for its generated music and effects.

Experience:

* Futuristic laser weapons.
* Cinematic explosions.
* Energy shield impacts.
* Sci-fi emergency alarms.
* Powerful boss attacks.
* Dynamic synthwave soundtracks.
* Atmospheric cosmic melodies.

The soundtrack dynamically adapts to the game’s atmosphere, transitioning between menu, combat, and boss encounters.
